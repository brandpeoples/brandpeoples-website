# brandpeoples-website

Official web application for **Brand Peoples** — custom merchandise, corporate apparel, and specialized textile manufacturing platform (Tiruppur, India). Built with Angular 21, Tailwind CSS, Three.js 3D WebGL Customizer Studio, and GSAP animations.

## Development Server

Run:
```bash
npm install
npm start
```
Navigate to `http://localhost:4201/` (or `http://localhost:4200/`). The application will automatically reload if you change any source files.

## Production Build

To build the project for production:
```bash
npm run build
```
Build artifacts will be stored in the `dist/` directory.

## Core Features

- **3D Customizer Studio (`/customize`):** Interactive WebGL 3D parametric simulator with real-time silhouette customization, chest placement mapping, fine-grain millimeter adjustments, and live sketch pad.
- **Capabilities (`/capabilities`):** Overview of manufacturing technologies, high-density 3D silicone, DTF heat transfers, and production capacity.
- **Quality Lab (`/quality`):** Interactive quality control cockpit, laser scanlines, and real-time stress testing simulations.
- **Catalogs & Gift Kits (`/catalog`, `/gift-kits`):** Curated product collections, corporate kits, and live inquiry flows.
- **Contact & WhatsApp Desk (`/contact-us`):** Direct Tiruppur factory quotes and rapid SLA dispatch.
